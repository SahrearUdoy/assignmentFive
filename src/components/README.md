<!-- Project Name:  -->

Dev Stack Builder

<!-- Project description : -->

Dev Stack Builder is a React-based website that helps developers explore different technologies and build their ideal development stack.

<!-- 3 Features : -->

- Explore different development technologies.
- Add technologies to a personal stack and remove them when needed.
- View technology details including category, difficulty, and rating.

1. What is JSX, and why is it used in React?

JSX is just a syntax that allows us to write codes like HTML inside JavaScript.Its used in react because it makes it easier to understand.

2. What is the difference between Props and State?

Props are data passed from a parent component to a child.State is data managed and changed inside a component.

3. What is the useState hook, and how do you use it?

useState is a React Hook used to create and update state; you use it by first importing it ,then giving it two parameters ,first ones value is set inside the useState,the second ones value changes in a function.

4. What is the useEffect hook, and why might it be needed for fetching JSON data?

useEffect is used to fetch JSON data when a component loads.

5. What is the purpose of the unique key prop when rendering lists?

The key prop gives each list item a unique identity so React can keep track of them.

6. How do you conditionally render components in React?

shows different content based on a condition.for example,the stack shows "No technologies selected yet" when it is empty.

7. How do you pass data from a parent component to a child component, and how can a child send data back to the parent?

A parent passes data with props,and a child can send data back by calling a callback function passed through props.
